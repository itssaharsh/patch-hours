# Product feedback

| Tool | What it was for | What worked | What needs work | Onboarding | Would build with it again |
|---|---|---|---|---|---|
| Vega SDK 0.24 + CLI | the Fire TV app | `vega project generate`, `npm run build:debug`, `vega run-app` worked first time; React Native 0.83 felt familiar | silent failures on the virtual device (see FRICTION_LOG.md 1, 2, 4) | one script install, about 20 minutes | yes |
| Vega Virtual Device | running the app with no Fire TV | booted under WSL2 once two packages were added; remote control on screen | no screenshot command; slow video decode on 4 cores | needed `libpulse0` and the `kvm` group | yes |
| `@amazon-devices/react-native-w3cmedia` | the reward video | the `Video` component played HTTPS MP4 with standard `play()`/`pause()` and events; changing `src` mid-show and seeking worked, which let the app fall back to a silent copy when the audio clock stalls | empty `MediaError.message`; no complete URL example; a second player (`Audio`) froze the JS thread on the virtual device and the app was killed as not responding, visible only in `vlcm crash-history` | README only | yes |
| Vercel | web app, API, hosting the clip | deploy from the CLI in under a minute | build fails on `new Date()` in a client component during prerender (clear message) | already set up | yes |
| Neon (via the Vercel Marketplace) | storing pairing sessions | provisioned from the CLI with env vars pulled | Upstash needed terms accepted in a browser, so we used Neon | one command | yes |
| MediaPipe Tasks Vision | face landmarks and eye-crop embeddings on the phone | runs in the browser with self-hosted models | logs an INFO line as a console error | docs clear | yes |
| Amazon Bedrock (Nova 2 Lite) | phrasing the week note and the child's cheer | one prompt shape gives clean JSON at low temperature; Nova 2 Lite is fast and cheap enough to call once per changed week | on a new account the model quota was 0 and the increase request was declined; `Converse` then answers only `ValidationException: Operation not allowed`, which reads like a bad request, and `GetFoundationModelAvailability` says `NOT_AUTHORIZED` without saying why. We reached the same model through Vercel AI Gateway, which serves it from Bedrock | the IAM and CloudFormation side took minutes; model access was the blocker | yes, once the quota is granted |
| Amazon Bedrock Guardrails | screening every generated text | `ApplyGuardrail` screens text we already have, from any model, so it worked even without model access; a denied topic caught "you can stop patching now" on the first try | a denied topic can't be tested in CloudFormation before deploying; a dry-run would help | one template resource and one API call | yes |
| Amazon Polly | the cheer and the pause prompt, spoken | generative voices sound natural for a young child; `StartSpeechSynthesisTask` writes straight to S3 | none worth noting | minutes | yes |
| Amazon S3, AWS CloudFormation, AWS IAM (OIDC from Vercel) | voice clips, one-template setup, keyless access | the guardrail, bucket, OIDC provider and role in one template; the app holds no AWS keys | template keys can't use `!Sub` (the trust policy had to be a JSON string) | about 30 minutes | yes |
| Vercel AI Gateway | reaching Amazon Nova when our Bedrock quota was 0 | works from the deployed app with its own OIDC token, no API key; the model list shows Bedrock as the provider | none worth noting | minutes | yes |
